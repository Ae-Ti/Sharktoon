# 약관과 개인정보 처리방침

`terms.md` 와 `privacy.md` 가 원본이고, `/terms` `/privacy` 화면이 이 파일을 그대로 그린다.
화면에 복사본을 두지 않으므로 문구를 고칠 곳은 여기 한 곳뿐이다.

## 예비창업 단계에서 채울 것

사업자 등록 전이라도 **무료 클로즈드 베타는 개인 운영으로 열 수 있다.** 판매가 없으면 통신판매업 신고와
사업자 정보 표시 의무가 생기지 않는다. 개인정보 처리는 개인도 할 수 있고, 보호책임자는 운영자 본인이 맡는다.
그래서 문서를 "사업자 등록 전 개인 운영"으로 고쳤고, 지금 채울 칸은 셋뿐이다.

| 자리 | 무엇을 |
|---|---|
| `[운영자 성명]` | 본인 이름. 약관 제3조와 처리방침의 회사 표시·보호책임자에 들어간다 |
| `[문의 이메일]` | 받는 메일 주소 하나. 개인 메일도 되지만 서비스용 주소를 하나 만드는 걸 권한다 |
| `[시행일]` | 베타를 여는 날. 두 문서와 약관 부칙을 같이 고친다 |

이미지 모델이 정해지면 처리방침 6항의 `[이미지 생성 제공자]` 와 `[보관 기간]` 을 채운다.

### 단계별로 생기는 의무

| 시점 | 해야 할 것 |
|---|---|
| 무료 베타(지금) | 위 세 칸. 약관·처리방침 게시, AI 사전 고지(로그인 화면에 있음) |
| 유료 결제 전 | 사업자 등록(개인사업자도 됨) → PG 가맹 심사 → 통신판매업 신고(PG 의 구매안전서비스 확인증 필요). 그 뒤 약관 제3조 제3항대로 상호·대표자·주소·전화·사업자번호·신고번호를 표시하고 공지 |
| 법인 설립 시 | 운영 주체가 바뀌므로 약관·처리방침의 회사 표시를 바꾸고, 회원에게 개인정보 이전(영업 양수) 사실을 알린다 |

예비창업패키지 같은 지원사업에 붙어도 협약 전까지는 개인 운영이다. 그 전에 결제를 열지 않으면 된다.

### 확인이 필요한 값

- 처리방침 6항의 Supabase·Vercel·Anthropic 개인정보 문의처는 각 사의 개인정보 처리방침에 공개된 주소로 넣었다. 계약(DPA) 시 다시 확인한다.
- Anthropic 보관 기간(30일, 위반 확인 시 더 길게)은 공개 정책 기준이다.

## 변호사 확인을 권하는 것

1. **AI 생성물 저작권과 이용자 창작 기여의 범위** — 판례가 없다.
2. **유료 크레딧 환불 공제율(10%)과 구독 크레딧 단가 계산** — 지침 기준이지만 상품 구성이 정해지면 다시 본다.
3. **국외 이전** — 이미지 생성 제공자가 정해지면 DPA 의 보관 기간·학습 미사용 조항을 확인하고 실명으로 적는다.
4. **AI 기본법 표시 방식** — 시행령·고시의 표시 방법(가시적 표시와 메타데이터)과 우리 방식(화면 배지 + PNG 메타데이터, 이미지 위 워터마크는 무료 요금제만)이 맞는지.

## 바꾸는 절차

이용자에게 불리한 변경은 적용일 30일 전 게시와 개별 통지가 필요하다(약관 제4조, 처리방침 15항).
문구를 고치면 파일 상단의 시행일과 약관 부칙을 같이 고친다.
