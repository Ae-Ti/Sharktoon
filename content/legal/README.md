# 약관과 개인정보 처리방침

`terms.md` 와 `privacy.md` 가 원본이고, `/terms` `/privacy` 화면이 이 파일을 그대로 그린다.
화면에 복사본을 두지 않으므로 문구를 고칠 곳은 여기 한 곳뿐이다.

## 베타 전에 채워야 하는 것

대괄호로 남겨둔 자리는 사람이 정하거나 계약으로 확인해야 하는 값이다.

| 자리 | 누가 / 언제 |
|---|---|
| `[시행일]` | 클로즈드 베타 날짜를 다시 정할 때. 두 문서와 약관 부칙을 같이 고친다 |
| `[대표자 성명]`, `[사업장 주소]`, `[고객센터 전화번호]`, `[고객문의 이메일]`, `[사업자등록번호]` | 태일. 전자상거래법 제13조 표시 의무 |
| `[통신판매업 신고번호]` | 유료 결제를 열기 전에 신고. 무료 베타만 할 때는 비워 둬도 되지만 결제 오픈 전에는 필수 |
| `[성명]`, `[직책]`, `[이메일]`, `[전화번호]` — 개인정보 보호책임자 | 태일. 법상 지정 의무 |
| `[결제대행사]` | 토스페이먼츠 심사 후 |
| `[이미지 생성 제공자]` 와 `[보관 기간]` | 이미지 모델 확정 후. 국외 이전 고지에 실명·국가·연락처가 들어가야 한다 |
| 국외 이전 각 항목의 `[연락처]` | 각 제공자의 개인정보 문의처(DPA 또는 개인정보 처리방침에 있다) |
| Anthropic `[보관 기간]` | API 데이터 보관 기간을 계약(상용 약관·DPA)에서 확인해 적는다 |

상호는 PRD 의 "가보자IT" 로 적었다. 법인이면 "주식회사 가보자IT" 처럼 등기상 정확한 이름으로 바꾼다.

## 문서에 맞춰 코드가 해야 하는 것

약관에 적은 대로 동작해야 한다. 지금 되는 것과 결제 오픈 전에 만들어야 하는 것.

| 약관 | 상태 |
|---|---|
| 실패하면 크레딧 환불(제8조 제2항) | 됨 |
| 필터에 막히면 차감 안 함 | 됨 |
| 생성물 AI 표시(화면 배지 + PNG 메타데이터) | 됨 |
| AI 기반 서비스 사전 고지 | 됨(로그인 화면) |
| 셀카 원본 즉시 삭제 | 됨 |
| 차감 전 차감량 표시 | 됨(버튼의 "N크레딧") |
| **무상 → 구독 → 구매 순 차감, 유료분 환불 계산** | **결제 오픈 전에.** 지금 원장은 크레딧 종류를 구분하지 않는다. `credit_accounts` 를 종류별 잔액으로 나눠야 한다 |
| 탈퇴 화면(유료 잔여분 안내, 30일 내 철회) | 결제 오픈 전에 |
| 이용 제한 시 사유 통지·이의 제기 | 공개 피드(오픈 베타) 전에 |
| 구독 가격 인상 30일 전 통지·동의 | 결제 오픈 전에 |
| 필터 판정 기록 1년 보관 | 지금은 기록을 안 남긴다. 남기기 시작하면 이 기간을 지킨다 |

## 변호사 확인을 권하는 것

1. **AI 생성물 저작권과 이용자 창작 기여의 범위** — 판례가 없다.
2. **유료 크레딧 환불 공제율(10%)과 구독 크레딧 단가 계산** — 지침 기준이지만 상품 구성이 정해지면 다시 본다.
3. **국외 이전** — 이미지 생성 제공자가 정해지면 DPA 의 보관 기간·학습 미사용 조항을 확인하고 실명으로 적는다.
4. **AI 기본법 표시 방식** — 시행령·고시의 표시 방법(가시적 표시와 메타데이터)과 우리 방식(화면 배지 + PNG 메타데이터, 이미지 위 워터마크는 무료 요금제만)이 맞는지.

## 바꾸는 절차

이용자에게 불리한 변경은 적용일 30일 전 게시와 개별 통지가 필요하다(약관 제4조, 처리방침 15항).
문구를 고치면 파일 상단의 시행일과 약관 부칙을 같이 고친다.
