# 약관과 개인정보 처리방침

`terms.md` 와 `privacy.md` 가 원본이고, `/terms` `/privacy` 화면이 이 파일을 그대로 그린다.
화면에 복사본을 두지 않으므로 문구를 고칠 곳은 여기 한 곳뿐이다.

## 베타 전에 채워야 하는 것

대괄호로 남겨둔 자리는 전부 사람이 정해야 한다.

| 자리 | 누가 |
|---|---|
| `[회사명]`, `[사업자등록번호]` | 태일 |
| `[고객문의 이메일]` | 태일 |
| `[성명]`, `[직책]`, `[이메일]`, `[전화번호]` — 개인정보 보호책임자 | 태일. 법상 지정 의무가 있다 |
| `[결제대행사]` | 토스페이먼츠 심사 완료 후 |
| `[이미지 생성 API 제공자]` 와 소재 국가 | 오픈 이슈 1(모델 선정) 확정 후. **국외 이전 고지에 실명이 들어가야 한다** |

## 초안이라는 것

이건 법무 검토를 받지 않은 초안이다. 특히 아래 세 가지는 변호사 확인을 권한다.

1. **AI 생성물의 저작권 귀속** — 판례가 확립되어 있지 않아 "이용 권한은 이용자에게, 저작권 발생은 보장하지 않음"으로 썼다.
2. **크레딧 청약철회 제한** — 디지털 콘텐츠 사용 개시 시 철회 제한을 적용했다. 크레딧을 일부만 쓴 경우의 잔여분 환불 처리는 다툼의 여지가 있다.
3. **국외 이전** — 이미지 생성 API 제공자가 확정되면 그 국가와 항목을 정확히 기재해야 한다. 이게 비어 있으면 처리방침이 미완이다.

## 바꾸는 절차

이용자에게 불리한 변경은 적용일 30일 전 공지가 필요하다(약관 제3조, 처리방침 14항).
문구를 고치면 파일 상단의 시행일도 같이 고친다.
