# 컷 편집기 캔버스 규칙

디자인 가이드가 "컷 편집기 캔버스 안쪽(레이어 핸들, 마스크 브러시 커서, 스냅 가이드)의
시각 규칙은 react-konva로 실제 인터랙션을 만들면서 정한다"고 미뤄 둔 것을 정한 기록이다.
구현은 `src/features/generation/editor/` 에 있다.

## 좌표

**레이어 값은 전부 컷 이미지 원본 픽셀이다.** 인스타 1:1 기준 1080×1080이고,
화면 배율은 konva `Stage` 의 `scale` 로만 준다.

이렇게 하는 이유는 두 가지다. 확대·축소를 해도 레이어 값이 흔들리지 않고,
내보낼 때 화면 배율과 무관하게 원본 크기로 그대로 그린다. 화면 픽셀로 저장하면
창 크기가 다른 기기에서 연 다음 저장하는 순간 레이아웃이 밀린다.

`useMeasuredSize` 가 캔버스 칸의 폭을 재서 넘긴다. konva `Stage` 는 CSS 로 늘릴 수
없고 픽셀 크기를 받아야 해서, 부모를 `ResizeObserver` 로 재는 것 말고 방법이 없다.

## 조작

| 동작 | 입력 | 이력 |
|---|---|---|
| 선택 | 레이어 클릭·터치 | 안 쌓임 |
| 선택 해제 | 빈 곳 클릭, Esc | 안 쌓임 |
| 이동 | 드래그 | 조작이 **끝날 때** 한 칸 |
| 크기·회전 | Transformer 핸들 | 조작이 **끝날 때** 한 칸 |
| 글자·말풍선·크기 변경 | 오른쪽 패널 | 즉시 한 칸 |
| 순서 변경 | 레이어 행의 ▲▼ | 즉시 한 칸 |
| 삭제 | Delete·Backspace, 패널 버튼 | 즉시 한 칸 |

**드래그 한 번은 이력 한 칸이다.** 드래그 중에는 `preview` 로 현재 값만 바꾸고
이력에 쌓지 않는다. 안 그러면 실행 취소를 60번 눌러야 원위치가 된다.
조작 시작은 캔버스가 `onDragStart`/`onTransformStart` 로 알려주고, 그때의 트리가
"이전 칸"이 된다.

잠근 레이어(`locked`)는 드래그도 키보드 삭제도 안 된다. 배경을 실수로 끄는 일이
제일 잦아서 배경은 기본 잠금이다.

## 핸들

- 앵커 12px, 모서리 반경 3px, 테두리 1.5px — **전부 캔버스 배율로 나눠서** 넘긴다.
  그래야 확대해도 핸들이 같은 크기로 보인다.
- 최소 크기 24×24. 더 작아지면 핸들을 다시 잡을 수 없다.
- 회전 허용. 효과음이 기울어져야 인스타툰처럼 보인다.

## 말풍선

12종을 `Rect` 의 모서리 반경·선 두께·점선으로 구분한다. 종류별 값은
`EditorCanvas.tsx` 의 `BALLOON_SHAPE` 에 있다.

- 일반·연결: 반경을 높이의 45% 까지(최대 48px), 선 3px
- 생각·구름: 반경을 높이의 50%(완전한 타원), 선 3px
- 속삭임: 일반과 같은 모양에 점선 `[12, 8]`, 선 2px
- 외침·뾰족: 반경 8px 이하, 선 4px — 각져야 세게 읽힌다
- 텔레파시: 타원에 점선 `[4, 6]`, 선 2px
- 방송: 반경 6px 에 긴 점선 `[16, 6]`
- 나레이션 박스: 반경 6px, 선 1.5px — 대사가 아니라 배경이라 가장 얇다

### 꼬리

`VectorTextLayer.tail` 은 꼬리 끝점이다(컷 원본 좌표). 모양 계산은 `shapes.ts`, konva 설정은
`nodeConfig.ts` 에 있고 **편집 캔버스와 내보내기 렌더러가 같은 함수를 쓴다** — 화면과 PNG 가 같아야 한다.

- 쐐기: 밑변을 끝점 쪽 변 위에 두되 모서리 둥근 부분(양끝 20%)은 피한다. 밑변 반폭은 몸통 짧은 변의 12%(최소 10px).
- 몸통 위에 그린다. 채운 삼각형이 밑변의 몸통 테두리를 덮고, 선은 두 옆변에만 긋는다 — 그래야 한 덩어리로 보인다.
  밑변은 테두리를 덮도록 4px 안쪽으로 넣는다.
- 생각·구름 풍선은 쐐기 대신 작아지는 동그라미 셋.
- 텔레파시·나레이션 박스·꼬리 없음은 꼬리를 그리지 않는다.
- 끝점이 몸통 안쪽이면 그리지 않는다.
- 말풍선을 끌면 꼬리 끝점도 같이 움직인다(`useEditor.previewBox`). 꼬리만 남아 엉뚱한 곳을 가리키지 않게.
- 선택한 말풍선의 끝점에 흰 동그라미 핸들이 뜬다. 끌면 이력 한 칸.
- 회전한 말풍선의 꼬리는 회전을 따르지 않는다. 말풍선을 돌릴 일이 드물어 미뤘다.

글자 여백은 말풍선 폭의 6% 다. 고정 px 로 두면 작은 말풍선에서 글자가 다 잘린다.
효과음처럼 획이 있는 글자는 `fillAfterStrokeEnabled` 를 켠다 — 안 켜면 획이
글자 안쪽을 먹어서 굵은 글자가 뭉갠 것처럼 보인다.

## 자동 저장

마지막 변경에서 **3초** 뒤에 보낸다(PRD 비기능 요구사항). 저장 버튼은 두지 않는다.
상태는 툴바 오른쪽에 글자로만 보여주고(`저장 대기 중 / 저장 중 / 저장됨`),
실패해도 편집은 계속된다 — 다음 변경에서 다시 시도한다.

## 스냅 가이드

끄는 동안 캔버스 가장자리·중앙선, 다른 레이어의 변·중심에 붙는다. 거리는 **화면 8px**
(캔버스 배율로 나눠 원본 좌표로 바꾼다). 붙은 선은 브랜드 색 점선으로 보이고 놓으면 사라진다.
배경과 숨긴 레이어는 기준이 되지 않는다. 회전한 레이어는 변이 축과 맞지 않아 붙이지 않는다.

## 확대

두 손가락 핀치(모바일)와 Ctrl+휠·트랙패드 핀치(데스크톱)로 100~400% 확대한다.
**보기 배율이라 레이어 값에 닿지 않는다.** 그냥 휠은 페이지 스크롤로 둔다.
확대 중에는 오른쪽 아래에 배율과 "맞추기" 버튼이 뜬다. 핀치가 시작되면 끌던 레이어는 놓는다.
두 손가락 회전은 하지 않았다 — 회전은 Transformer 핸들로 한다.

## 작품 안 글꼴

`fonts.ts` 의 31종. 전부 Google Fonts 의 **SIL Open Font License** 글꼴이라 상업 이용과
이미지 내보내기가 된다. 손글씨 8 · 둥근 4 · 굵은 4 · 고딕 4 · 명조 5 · 장식 6.

| 성격 | 글꼴 |
|---|---|
| 손글씨 | Gaegu(기본), Nanum Pen Script, Nanum Brush Script, Gamja Flower, Hi Melody, Poor Story, Single Day, Kirang Haerang |
| 둥근 | Cute Font, Jua, Dongle, Gowun Dodum |
| 굵은 | Do Hyeon, Black Han Sans, Bagel Fat One, Gasoek One |
| 고딕 | Noto Sans KR, Nanum Gothic, Gothic A1, Orbit |
| 명조 | Noto Serif KR, Nanum Myeongjo, Gowun Batang, Song Myung, Hahmlet |
| 장식 | Yeon Sung, Dokdo, East Sea Dokdo, Stylish, Gugi, Diphylleia |

- 쓰는 글꼴만 그때 불러온다. 한글 글꼴 31종을 미리 받으면 수 MB 다.
- 굵기를 지정해 요청하지 않는다. 대부분의 한글 손글씨체는 400 하나뿐이라 `wght@400;700` 요청이 통째로 400 오류가 난다.
  굵게는 브라우저가 합성한다.
- konva 는 캔버스에 그리므로 글꼴이 오기 전에 그리면 대체 글꼴로 굳는다. 다 받은 뒤 텍스트 노드를 다시 만든다(`useFontEpoch`).
- Sunflower 는 기본 굵기가 없어 요청이 실패해 뺐다.

## 처음 여는 컷

컷을 처음 열면 생성 이미지를 잠긴 배경으로 깔고, 콘티의 글을 벡터 레이어로 얹는다(`buildLayerTree.ts`).
1컷에는 고른 후킹, 마지막 컷에는 고른 CTA, 대사는 위에서부터 좌우로 엇갈린 말풍선(꼬리는 아래 가운데),
화자 없는 대사는 기울어진 효과음, 나레이션은 아래쪽 나레이션 박스다. 이미지 위에 바로 얹는 글자는
흰 글자에 진한 테두리 — 어떤 배경에서도 읽힌다.

한 번 저장하면 그 뒤로는 저장된 트리를 쓴다. 이미지 URL 은 서명 URL 이라 저장하지 않고 열 때마다
다시 붙인다. 그래서 컷을 다시 생성해도 레이어 배치는 그대로고 그림만 바뀐다.

## 저장

마지막 변경 3초 뒤(PRD). 다른 컷으로 넘어가거나 화면을 떠날 때는 기다리지 않고 바로 보낸다 —
안 그러면 마지막 변경이 디바운스 안에서 사라진다.

## 내보내기

`exportCarousel.ts`. 브라우저에서 원본 배율(1080 폭)로 다시 그려 PNG 로 뽑고 ZIP 으로 묶는다.
서버로 이미지를 보내지 않는다.

- 1:1(1080×1080)·4:5(1080×1350). 원본 비율과 다르면 흰 여백을 두고 가운데 맞춘다. 자르지 않는다.
- 모든 PNG 에 tEXt 청크로 AI 생성 표시: `Software`, `Comment`, IPTC `DigitalSourceType`(trainedAlgorithmicMedia).
  오픈 이슈 7(AI 라벨 표시 방식)의 1차안이다.
- 무료 요금제는 오른쪽 아래에 "샥툰으로 만듦" 워터마크.
- 서명 URL 이미지는 교차 출처라 `crossOrigin="anonymous"` 로 받아야 캔버스를 PNG 로 뽑을 수 있다.
