# 샥툰 디자인 가이드

화면 구조(와이어프레임)와 디자인 시스템은 문서가 아니라 **살아 있는 페이지 두 개**로 관리한다.
이 파일은 그 두 개로 가는 입구와, 코드베이스에서 토큰을 어떻게 쓰는지만 적는다.

| | 링크 | 무엇 |
|---|---|---|
| 디자인 시스템 | https://claude.ai/artifact/D1bKmcujemY68x3NPxCRuA | 색 28개·타입 9종·간격/모서리/그림자/컨트롤 토큰, 컴포넌트 11개(실제 동작하는 미리보기 + 사용 규칙), 브랜드 북 |
| 와이어프레임 | https://claude.ai/artifact/XLyoJNbUBfaGG8LhzKHKn4 | 클로즈드 베타 범위 11개 화면. 온보딩 6개(모바일 390) + 제작 운영 3개 + 편집·게시 2개(데스크톱 1280). 화면끼리 링크로 이어져 클릭해 볼 수 있다 |

## 코드에서 쓰기

- `design/tokens.css` — 컴파일된 CSS 커스텀 프로퍼티. `:root`가 라이트, `[data-theme="dark"]`가 다크다.
  `app/globals.css` 맨 위에서 `@import '../design/tokens.css';`
- `design/tailwind.theme.ts` — 위 변수를 가리키는 Tailwind 테마 확장.
  `tailwind.config.ts`에서 `theme: { extend: sharktoonTheme }`.
- 컴포넌트 구현체는 아직 레포에 없다. 디자인 시스템 페이지의 `components/bundle.js`가 참조 구현이고,
  Next.js에서는 같은 props로 다시 쓴다(`components/index.d.ts`가 타입 계약).

**토큰 값을 코드에 직접 박지 않는다.** `#0a7d8d`가 아니라 `var(--brand)` / `bg-brand`를 쓴다.
값을 바꿔야 하면 디자인 시스템 페이지에서 바꾸고 `design/tokens.css`를 다시 뽑는다.

## 이번에 정한 것

- **폰트**: Pretendard Variable(SIL OFL, 상업 이용 가능)을 self-host한다. 폴백은 Noto Sans KR → system-ui.
  말풍선·나레이션에 들어가는 **작품 안 글꼴은 UI 폰트와 별개**로, 상업 이용 가능 라이선스 목록으로 따로 관리한다.
- **색 대비**: 두 테마 모두에서 글자 4.5:1, 아이콘·컨트롤 경계 3:1을 계산해서 맞췄다.
  입력 경계는 `border`(장식)가 아니라 `border-control`(3:1)을 쓴다.
- **코랄(`accent`)은 크레딧 전용**이다. 크레딧이 아닌 곳에 이 색이 보이면 잘못 쓴 것이다.
- **터치 44px**: 모든 조작 요소 기본 높이는 `control-md`(44px). 데스크톱 전용 보조 동작만 36px.
- **로고 없음**: 전용 마크가 없어 워드마크 "샥툰"만 쓴다. 임의로 마크를 그리지 않았다.
