# 요금제 모델 — 무료 사용자 원가와 유료 전환율을 같이 본다

2026-10-03. 오픈 이슈 4(크레딧 단가와 요금제 가격) 결정의 근거.
결정 방향: **1컷 = 1크레딧은 유지하고 요금제 가격·크레딧 수·무료 지급량을 조정한다.**
숫자는 이미지 모델 비교 테스트(오픈 이슈 1)에서 실제 컷당 원가가 나오면 이 표로 다시 확정한다.

## 한 줄 결론

돈을 잃는 곳은 유료 요금제가 아니라 **무료 사용자에게 주는 크레딧**이다. 이전안(출석 하루 1 + 7일 보너스 3)은
무료 사용자 한 명이 한 달에 최대 약 42크레딧(원가 2,500~4,600원)을 가져간다. 유료 전환율이 아무리 높아도
그 손실을 메우지 못한다. 그래서 **출석 보상을 줄이고 한 달 상한을 둔 뒤**, 유료 요금제를 원가에 맞춘다.

## 가정

| 항목 | 값 | 근거 |
|---|---|---|
| 컷당 원가 | 60 / 85 / 110원 | 이미지 1장(1K) $0.034~0.07 + 레퍼런스 입력 + 실패·재시도 10%. 환율 1,380원 |
| 결제 수수료 | 3.3% | 웹 PG. 앱 인앱결제(15~30%)는 앱 판매가를 따로 올린다 |
| 부가세 | 판매가에 포함 | 판매가 ÷ 1.1 이 매출 |
| 유료 사용자 크레딧 사용률 | 70% | 구독 크레딧이 다 쓰이지 않는 몫(이월 50% 반영 전) |
| 무료 사용자 사용률 | 80% | 받은 크레딧은 대부분 쓴다고 본다(보수적) |
| 신규 비율 | 월 활성 무료 사용자의 30% | 가입 보너스 8크레딧을 그 달에 쓰는 사람 |

계산은 "무료 사용자 1명의 월 원가"와 "유료 사용자 1명의 월 공헌이익(매출 − 원가)"을 놓고,
둘이 같아지는 유료 전환율(손익분기)을 구했다. 일반적인 소비자 앱의 무료→유료 전환율은 2~5% 다.

## 무료 지급량이 가장 큰 변수다

베이직 14,900원 / 80크레딧 기준, 무료 사용자의 출석 크레딧 한 달 상한에 따른 손익분기 전환율.

| 컷당 원가 | 상한 0 | 상한 3 | 상한 6 | 상한 13(≈이전안 출석) |
|---|---|---|---|---|
| 60원 | 1.3% | 2.7% | 4.1% | 7.2% |
| 85원 | 2.2% | 4.4% | 6.6% | 11.4% |
| 110원 | 3.3% | 6.7% | 9.9% | 16.6% |

이전안(9,900원 / 200크레딧 + 출석 하루 1)은 원가 60원에서도 100명당 월 7만 원 넘게 적자였다.
1크레딧이 약 50원이라 **유료 사용자에게서도 손해**를 본다.

## 제안

| 항목 | 이전 | 제안 | 1크레딧당 |
|---|---|---|---|
| 가입 보너스 | 8 | **8 (유지)** | 첫 화 6컷 + 재시도. 첫 게시 완주율(베타 출시 조건)을 지키려고 줄이지 않는다 |
| 출석 | 하루 1 + 7일 연속 3 | **하루 0.5 + 7일 연속 1, 한 달 3까지** | 출석은 습관 장치로 남기되 원가 상한을 둔다 |
| 무상 크레딧 유효기간 | 없음 | **90일** | 쌓아 두었다 한꺼번에 쓰는 원가를 막는다 |
| 베이직 | 9,900원 / 200 | **14,900원 / 80** | 186원. 월 약 12화(주 2~3화 연재) + 다시 만들기 |
| 프로 | 19,900원 / 600 | **29,900원 / 200** | 150원. 매일 연재, 애니메이션(1화 5크레딧) |
| 크레딧 팩 | 미정 | **20크레딧 4,900원** | 245원. 구독 없이 한 화 더 |

제안 요금의 손익분기 전환율:

| 컷당 원가 | 무료도 같은 모델 | 무료 사용자만 절반 원가 등급* |
|---|---|---|
| 60원 | 2.7% | 1.4% |
| 85원 | 4.4% | 2.3% |
| 110원 | 6.7% | 3.5% |

\* 무료 사용자의 생성(가입·출석 크레딧)은 같은 모델의 저가 등급(예: Lite·Mini 계열)이나 낮은 해상도로
돌리는 안. 첫 화 품질이 첫 게시 완주율에 직결되므로 **가입 보너스 8크레딧은 정상 등급**으로 두고
출석 크레딧만 저가 등급으로 돌리는 절충을 권한다. 모델 비교 테스트에서 저가 등급 품질도 같이 본다.

**원가가 85원을 넘으면** 베이직을 80 → 60크레딧으로 줄이거나 가격을 올려야 한다. 비교 테스트 결과를
이 표에 넣어 다시 정한다.

## 코드에 들어간 것

- 출석·가입 보너스·유효기간·환불 공제율은 `credit_policy` 테이블 한 행이다(마이그레이션 0008).
  **값을 바꾸는 데 배포가 필요 없다.** 화면 문구(홈의 출석 배너, 설정)가 이 값을 그대로 읽는다.
  ```sql
  update credit_policy set attendance_daily = 0.5, attendance_monthly_cap = 3;
  ```
- 요금제 가격은 아직 코드에 없다. 결제대행사를 붙일 때(사업자 등록 후) 상품표로 넣는다.

## 다시 계산하려면

이 문서의 숫자는 아래 식으로 냈다. 가정을 바꾸면 그대로 다시 돌린다.

```
무료 1명 월 원가 = (출석 상한 × 0.8 + 0.3 × 가입 8 × 0.9) × 컷당 원가 × 등급 비율
유료 1명 공헌    = 판매가 ÷ 1.1 × (1 − 0.033) − 월 크레딧 × 0.7 × 컷당 원가
손익분기 전환율  = 무료 원가 ÷ (유료 공헌 + 무료 원가)
```
