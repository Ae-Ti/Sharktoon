# 접점 계약

두 사람의 코드가 만나는 지점의 타입만 여기 둔다. 부록 E "공통: 착수 첫 주에 함께 확정"에 해당한다.

| 파일 | 오너 | 상대가 하는 일 |
|---|---|---|
| `credit.ts` | 태일(B) | 웅싯은 `CreditLedger`를 호출만 하고 구현하지 않는다 |
| `generation.ts` | 웅싯(A) | 태일은 `GenerationJob` 상태를 읽어 화면에 그린다 |

**여기 있는 타입은 상대 합의 없이 바꾸지 않는다.** 바꿔야 하면 PR에서 서로 리뷰한다.
`generation.ts`는 태일이 먼저 올린 초안이므로, 웅싯이 실제 파이프라인에 맞게 고치는 것을 전제로 한다.
